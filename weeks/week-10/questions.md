# Вопросы для самопроверки

1. Что такое слой в Docker и почему порядок команд в Dockerfile важен для кэширования?

- Слой (layer) — это результат каждой команды в Dockerfile. Docker кэширует слои, поэтому если изменить команду в начале, пересоберутся все последующие. Поэтому сначала ставят зависимости, потом копируют код.

2. В чем суть Multi-stage build? Какие проблемы он решает?

- Это сборка в несколько этапов: сначала собираем зависимости/бинарники, потом копируем только результат в чистый образ. Решает проблему большого размера и лишних инструментов в финальном контейнере.

3. Зачем нужен файл `.dockerignore`?

- Чтобы исключить ненужные файлы (git, venv, тесты) из сборки. Это уменьшает размер образа и ускоряет сборку.

4. Чем отличаются инструкции `CMD` и `ENTRYPOINT`?

- CMD — задаёт команду по умолчанию (можно переопределить).
- ENTRYPOINT — фиксирует основную команду (сложнее переопределить).

5. Почему рекомендуется использовать `COPY` вместо `ADD`?

- COPY проще и предсказуемее. ADD делает лишние вещи (распаковка архивов, скачивание URL), что может быть небезопасно.

6. Почему приложение в контейнере должно слушать `0.0.0.0`, а не `127.0.0.1`?

- 127.0.0.1 доступен только внутри контейнера, а 0.0.0.0 позволяет принимать подключения извне (с хоста).

# Вопросы для самопроверки

- CI проверяет код, Delivery готовит релиз, Deployment выкатывает автоматически.
- Тесты до build/push экономят время и не публикуют сломанный образ.
- Кэш ускоряет установку зависимостей.
- Secret - скрытая переменная; пароль Docker Hub хранить в GitHub Secrets.
- Matrix Build запускает один workflow с разными версиями/ОС/параметрами.
- Prod-конфиги опасны секретами и случайным изменением окружения.

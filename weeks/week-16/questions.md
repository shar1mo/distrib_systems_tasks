# Вопросы для самопроверки

- OWASP Top 10 - частые риски: access control, injection, misconfiguration.
- Аутентификация проверяет личность, авторизация проверяет права.
- SQL Injection - внедрение SQL; ORM параметризует запросы.
- Секреты в репозитории легко утекут в историю Git.
- MitM перехватывает трафик; HTTPS шифрует и проверяет сертификат.
- Least Privilege уменьшает ущерб при взломе.

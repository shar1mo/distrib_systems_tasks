# Checklist

- Проверить авторизацию на каждом endpoint.
- Проверить SQL/command injection во входных полях.
- Проверить валидацию JSON payload.
- Проверить хранение секретов вне репозитория.
- Проверить HTTPS/TLS для внешнего трафика.
- Проверить срок жизни JWT/session token.
- Проверить защиту от перебора паролей.
- Проверить CORS только для доверенных origin.
- Проверить отсутствие debug-режима в prod.
- Проверить минимальные права сервисного аккаунта.
- Проверить лимиты ресурсов контейнера.
- Проверить, что логи не содержат токены и пароли.

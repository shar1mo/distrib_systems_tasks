# Вопросы для самопроверки

Постарайтесь ответить на эти вопросы своими словами, чтобы закрепить материал.

1. В чем разница между "ресурсом" и "коллекцией" в контексте REST API?

- Ресурс — это один конкретный объект (например, один пользователь с id=1).
Коллекция — это набор таких объектов (например, список всех пользователей).

2. Почему для создания объекта используется метод `POST` и код ответа `201`, а не `200`?

- POST используется для создания нового ресурса. Код 201 Created означает, что объект успешно создан. 200 OK просто говорит, что запрос выполнен успешно, но не подчеркивает факт создания нового ресурса.

3. Что такое идемпотентность? Назовите HTTP-методы, которые являются идемпотентными.

- Идемпотентность — это свойство, при котором повторный одинаковый запрос не меняет результат после первого выполнения. Идемпотентные методы: GET, PUT, DELETE. POST не является идемпотентным.

4. Почему ID объекта обычно генерируется на сервере и возвращается в ответе на `POST`?

- Потому что сервер управляет данными и гарантирует уникальность ID. Клиент не должен придумывать ID сам, чтобы избежать конфликтов.

5. Что такое "контракт API" и почему важно его соблюдать?

- Контракт API — это договоренность между клиентом и сервером о формате запросов и ответов. Его важно соблюдать, чтобы клиент и сервер правильно понимали друг друга и система работала стабильно.

6. Зачем команде разработчиков нужна спецификация, например, OpenAPI (Swagger)?

- Спецификация описывает, какие есть методы, параметры и ответы.
Она помогает команде договориться о структуре API, автоматически генерировать документацию и упрощает тестирование и интеграцию.

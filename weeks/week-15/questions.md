# Вопросы для самопроверки

- Average скрывает хвосты; P95/P99 показывают худший опыт пользователей.
- Throughput - пропускная способность, обычно RPS.
- Точка насыщения - RPS почти не растет, latency резко растет.
- Большой payload увеличивает сеть, CPU и время сериализации.
- Localhost убирает сеть и может упереться в ресурсы клиента.
- Coordinated Omission - тест не учитывает задержки, пока генератор сам ждет ответ.
